# Personalized-AI-Assistant-Prototype
A personalized AI assistant educating women and girls about ADHD using a custom knowledge corpus.
Guide answers questions about ADHD using a custom-built corpus tailored to women and girls.
Powered by a retrieval system paired with an LLM, hosted as a simple web app.
🔗 Live Demo: https://mindie-guide--milancrittenden.replit.app/girlsinfocus/
